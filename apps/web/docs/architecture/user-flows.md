# User Flows

## First Visit

```txt
Home
-> Browse Games
-> Search
-> Game Details
-> Import BGG Collection
-> Dashboard
```

## Log New Play

```txt
Dashboard
-> New Play
-> Search Game
-> Select Players
-> Add Scores or Winner
-> Save
-> Dashboard Updated
```

## Browse Collection

```txt
Dashboard
-> Collection
-> Game Details
-> Statistics
-> Play History
```

## Explore Statistics

```txt
Dashboard
-> Statistics
-> Overall
-> Game Statistics
-> Player Statistics
```

## Manage Wishlist

```txt
Search
-> Game Details
-> Add to Wishlist
-> Wishlist
```

## Notes

- Start with read-only flows and mock data.
- Add write flows once the domain model is stable.
- Keep BGG import as a major onboarding path.
