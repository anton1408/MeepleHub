# MeepleHub Vision

## Mission

MeepleHub is a modern board game companion designed to help players manage their collection, track plays, and gain meaningful insights from their gaming history.

Unlike BoardGameGeek, which is primarily a board game database, MeepleHub focuses on the personal experience of every player.

## Goals

- Provide a clean and modern alternative for managing board game collections.
- Make logging a new play fast and effortless.
- Display useful statistics for games, players, and play sessions.
- Synchronize data with BoardGameGeek.
- Support both web and mobile applications from shared domain and API code.

## Non Goals

MeepleHub is not intended to replace BoardGameGeek.

It will not become a marketplace, forum, or review platform.

BGG remains the source of truth for board game information.

MeepleHub is a personal dashboard built on top of BGG.

## Target Users

- Board game enthusiasts
- Players with medium or large collections
- Gaming groups
- Statistics-focused users
- Users who regularly use BoardGameGeek

## MVP Scope

- Browse and search board games.
- View game details.
- Import a collection from BGG.
- Manage owned games and wishlist items.
- Log played sessions.
- Track basic game, player, and session statistics.

## Core Principles

- Fast
- Modern
- Clean UI
- Mobile friendly
- Component driven
- Open source friendly
